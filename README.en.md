## What the labels mean

- **Public prompts**: text the creator shared as a prompt or template, not necessarily their entire conversation or assets.
- **Author brief**: a description of the task; never presented as the complete prompt.
- **External playback**: a public GitHub attachment hosted by a third party, with its provider and original post recorded. We have not re-uploaded these videos or verified permission to redistribute them.
- **Metrics**: public post snapshots, not live X API statistics. Within each category, bookmarks sort first and likes break ties. Unknown values are shown as —. Popularity is not a quality score.
