# 发现与核验作品

候选作品整理自 X（Twitter）原作者公开帖子。正式收录前按以下顺序核对：

1. 确认原帖地址、作者、正文、发布时间和作品媒体；按主帖 ID 与现有案例去重，检查已删除作品记录，避免把转载或说明回复当作新作品。
2. 核对作者的创作声明、模型或工具在作品中的作用，以及原帖、公开回复和提示词之间的对应关系。把公开指令原文、任务描述和未知信息分别标记；不根据转述补写指令。
3. 核对视频与封面是否对应原帖，确认有可访问的作品入口。浏览器起播可用于检查画廊入口，不要求看完整片或听完整音轨。
4. 记录来源、核对时间和提示词状态。来源已核对、编目资料待完善的作品标为 `discovery`；资料整理完成后标为 `catalogued`。精选是独立编辑标记。

无法确认原作者创作、缺少直接作品媒体或来源核对失败的线索不进入公开案例。完整视听评价可另行开展；`verification.fullReview=false` 只表示尚未开展，不影响正常收录，不能在未审看时写成 `true`。权利人提出纠错或移除时，按[第三方内容说明](../THIRD_PARTY.md)和[维护指南](MAINTAINING.md)处理。各状态说明见[质量标准](QUALITY.md)。
