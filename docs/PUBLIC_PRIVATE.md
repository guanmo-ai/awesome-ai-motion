# 公开与本地资料边界

| 范围 | 内容 |
| --- | --- |
| 开源代码与自编文档 | 画廊、生成器、数据校验、测试、维护及贡献指南；适用仓库 MIT 许可。 |
| 公开案例资料 | 作者署名、原帖、独立撰写的简介、分类、来源依据、快照时间及核验状态。第三方内容不因进入本仓库而改为本站原创或纳入 MIT。 |
| 仅保存在本地 | 原始响应、搜索词与采集路线、采集工具、内部评估与任务分工、未收录候选、删除恢复记录、迁移备份和审计报告，统一放在 Git 忽略的 `.research/`。 |
| 不得进入公开文件或日志 | 私人身份与邮箱、机器名与本机路径、凭据、Cookie、认证配置及未获准公开的资料。 |

`data/cases.json` 本身是公开文件，不可当作内部数据库。其字段白名单由 `scripts/catalog-privacy.mjs` 检查；新增字段先明确读者用途和公开范围。媒体只保留来源与核验结果，不保存采集端点、请求细节或原始返回。

参考合集用于发现作者原帖。标题、简介和编排独立完成；确实使用过的来源保留必要署名，不通过改写或移除署名掩盖来源。作者原文、翻译和本站建议分开标注。未明确适合全文再分发的长篇指令可使用 `prompt.display=source_link`，仅公开来源链接；公开数据、双语页面及纯文本目录都不保留该全文或译文。作品权利与纠错入口见[第三方内容说明](../THIRD_PARTY.md)。

本地预览和静态打包使用文件白名单；发布检查同时检查工作树和 Git 暂存内容。`.gitignore` 不能清除已提交内容，自动检查也不能证明没有遗漏。修改公开边界时须检查生成文件、静态包及 Git 历史；历史重写、远端替换和重新部署属于单独操作。
