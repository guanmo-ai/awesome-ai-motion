# 来源与排序

案例整理自 X（Twitter）原作者公开帖子。每条作品提供作者与原帖链接；作者的公开回复可用于核对提示词和制作说明。模型、工具与制作过程按作者公开说明记录，本站未独立复现全部作品。发现线索须回到原作者作品核验，具体收录方法见[发现与核验](DISCOVERY.md)。

“公开提示词”指作者公开的指令原文，不代表完整对话、参考素材及修改过程均已公开。“任务描述”指作者对目标或过程的转述，不作为逐字提示词；未取得可核对指令时标为“未取得提示词”。译文和本站的创作建议与作者原文分开呈现。

首页及分类预览默认按原帖**收藏数快照**排序，可切换其他浏览方式。收藏数、点赞数和浏览量记录的是各条原帖在标示时间的公开数据，可能变化或缺失，并非实时统计，也不是作品质量评级；本站不声称由 X 官方 API 直接采集。缺失值不补造，显示为“—”。覆盖数量与编目状态见[覆盖范围](COVERAGE.md)和[收录标准](QUALITY.md)。

视频播放引用与原作者帖子对应的外部媒体，封面用于指向原作。来源核对与去重通过即可收录，完整视听评价是可选记录。链接可访问不代表取得重新上传许可。媒体与提示词的权利说明见[第三方内容](../THIRD_PARTY.md)。更新案例和指标的操作见[维护指南](MAINTAINING.md)。

公开文件、第三方引用与本地研究的边界见[公开范围说明](PUBLIC_PRIVATE.md)。长篇指令可仅保留作者原文入口；此时不提供全文、译文或文本下载。
