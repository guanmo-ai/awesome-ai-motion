# 质量状态与验收标准

本项目是案例目录。正常收录需要核对原帖、作者的模型或工具声明、作品媒体与原帖的对应关系，并按作品去重。`discovery` 表示来源已核对、编目资料待完善；`catalogued` 表示资料已整理。精选是独立编辑标记，不由编目阶段或收藏数自动决定。

| 范围 | 验收依据 |
| --- | --- |
| 来源与编目 | 能从案例回到原作者 X（Twitter）帖子，核对作者创作声明、模型或工具作用、媒体及提示词状态；按作品去重，已删除作品不因再次发现自动恢复。公开指令、任务描述和未知信息分别标记。 |
| 观看入口 | GitHub 首页、分类页及双语详情的封面和主观看链接打开对应画廊作品；无可播放来源时明确回退作者原帖。深链接指向正确作品和语言，画廊播放器可用时检查视频时间推进。 |
| 画廊与筛选 | 桌面和窄屏可找到对应作品；分类、搜索和筛选结果正确，关闭详情后能继续浏览。媒体错误或超时有可见提示、有界重试及作者原帖回退。 |
| 可选视听评价 | 需要作作品评价时，再观看完整片并听实际音轨，单独记录结果。`verification.fullReview=false` 表示未开展；不能因来源核对、编目、起播或精选而改为 `true`。这项评价不影响收录。 |
| 公开交付 | 生成内容与 `data/cases.json` 一致，运行受影响测试及 `node scripts/build.mjs --check`；准备发布时运行 `node --test tests/*.test.mjs`、`node scripts/check-release.mjs` 和 `node scripts/check-target.mjs`。只有实际可访问的公开页面才称为已上线。 |

外部视频由原媒体提供方托管。链接和播放测试仅说明检查时的可用性；是否可以重新上传或复用，应依[第三方内容说明](../THIRD_PARTY.md)核对权利。目录数字见[覆盖范围](COVERAGE.md)，新增作品的核验步骤见[发现与核验](DISCOVERY.md)。
