# 质量状态与验收标准

来源核对、媒体可取、浏览器起播、完整视听审看和编辑精选是不同状态。当前目录有 245 条案例，其中 209 条为待审看的发现池；案例数据尚未记录任何作品完成完整视听审看。编目、收藏数或精选标记都不能代替这项验收。

| 范围 | 验收依据 |
| --- | --- |
| 来源与编目 | 能从案例回到原作者 X（Twitter）帖子，核对作者创作声明、模型作用、媒体及提示词状态；按作品去重，已删除作品不因再次发现自动恢复。公开指令、任务描述和未知信息分别标记。 |
| 观看入口 | GitHub 首页、分类页及双语详情的封面和主观看链接打开对应画廊作品；无可播放来源时明确回退作者原帖。深链接指向正确作品和语言，浏览器里实际检查视频时间推进。 |
| 画廊与筛选 | 桌面和窄屏可找到对应作品；分类、搜索和筛选结果正确，关闭详情后能继续浏览。媒体错误或超时有可见提示、有界重试及作者原帖回退。 |
| 完整视听审看 | 以正常速度看完整片并听实际音轨，检查画面运动、转场、文字、旁白、音乐、音效和声画对应；无音轨须明确记录。封面、文件头、元数据、短时起播和自动测试均不能替代这一步。 |
| 公开交付 | 生成内容与 `data/cases.json` 一致，运行受影响测试及 `node scripts/build.mjs --check`；准备发布时运行 `node --test tests/*.test.mjs`、`node scripts/check-release.mjs` 和 `node scripts/check-target.mjs`。只有实际可访问的公开页面才称为已上线。 |

外部视频由原媒体提供方托管。链接和播放测试仅说明检查时的可用性；是否可以重新上传或复用，应依[第三方内容说明](../THIRD_PARTY.md)核对权利。目录数字见[覆盖范围](COVERAGE.md)，新增作品的核验步骤见[发现与核验](DISCOVERY.md)。
