## What to learn

Split a poem into scenes and let images and synthesized music follow the same imagery.

**Try it yourself** · Editorial suggestions based on public source material, not a complete record of the creator’s process.

1. Write an independent time-based Canvas scene for each couplet.
2. Build transitions, text reveals and seekable timing around the poem’s imagery.
3. Synthesize instruments with Web Audio and respect the separate code and content licenses.

Tools mentioned in the source：Canvas · Web Audio API · JavaScript
