## What to learn

Make the rules switchable in a program and compare one question through animation.

**Try it yourself** · Editorial suggestions based on public source material, not a complete record of the creator’s process.

1. Define distances, object count, speed and carrying rules.
2. Approve a static layout, then build two playable comparisons side by side.
3. Check text wrapping and mobile type size before exporting video.
