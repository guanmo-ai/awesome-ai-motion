## What to learn

Define animation as a function of time and render frames reproducibly.

**Try it yourself** · Editorial suggestions based on public source material, not a complete record of the creator’s process.

1. Define the format, duration and a direction using bold type, color blocks and camera moves.
2. Draw each frame from time in a single HTML file.
3. Capture frames with Playwright and assemble the video with FFmpeg.

Tools mentioned in the source：Opus 5.5 · HTML · Playwright · FFmpeg
