## What to learn

Coordinate characters, expressions, lip sync and lighting in code before staging a 3D short.

**Try it yourself** · Editorial suggestions based on public source material, not a complete record of the creator’s process.

1. Drive Blender with Python to model, rig and define expressions.
2. Stage props, keyframes and shots around the characters’ contest.
3. Handle character voices and synthesized music separately, then render in Eevee.

Tools mentioned in the source：Opus 5.5 · Python · Blender · Eevee · MiniMax TTS · NumPy
