## 可以借鉴什么

按诗句拆场景，让画面和合成音乐围绕同一意象展开。

**开始尝试** · 根据作者公开资料整理的编辑建议，并非作者完整操作记录。

1. 为每个诗句写独立的 Canvas 时间函数。
2. 按诗的意象组织转场、文字显现与可定位的播放时间。
3. 用 Web Audio 合成乐器，并按代码与内容的不同许可复用。

原文提到的工具：Canvas · Web Audio API · JavaScript
